Platform Starter Kit

Terraform + Kubernetes + ArgoCD + OPA Gatekeeper + Veeam Kasten

  • Terraform modules provisioning AKS clusters with configurable node pools, networking, RBAC, and remote state on Azure Storage; separate dev/prod environment configurations. Kasten storage module provisions Azure Blob backend with managed identity RBAC for K10 exports.
  • Veeam Kasten integration: K10 backup policy with daily snapshots, 7/4/3 GFS retention, and automated export to Azure Blob via managed identity; VolumeSnapshotClass with CSI annotation; OPA/Gatekeeper policy requiring StatefulSets to carry a k10.kasten.io/backup label, enforcing backup governance at the admission layer.
  • ArgoCD GitOps delivery with automated sync, self-heal for drift detection, and prune for removed resources; Application manifests managing Kasten infrastructure and application deployments from Git as source of truth.
  • Pod Security Standards (restricted profile), default-deny NetworkPolicies, Gateway API routing, Kustomize-based team onboarding with namespace isolation, resource quotas, RBAC bindings, and LimitRanges. Architecture decisions documented via ADRs.
